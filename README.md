# 晚间半小时

个人训练计划与打卡网页，周一胸背、周二腿、周三核心、周四臀；21:00–21:30。周五至周日不安排训练。

下载仓库后打开根目录 index.html，无需安装依赖。页面包含新版计划、动作步骤、负重摆位、常见错误、出处、打卡和反馈、次日睡眠补记、JSON 备份导入导出。

`tv/index.html` 是电视专用入口，提供遥控器导航、动态动作示范、每日热身与放松以及自动节奏提示。电视版不保存训练记录。电视浏览器可访问部署后的根网址；在 Vercel 中把这个仓库关联到现有项目，并将 Root Directory 设为 `tv`。

## 2026-10-14 更新

- 周一至周四分别 10、9、10、10 组；主要动作多为 3 组，核心/辅助多为 2 组。
- 30 分钟包括热身 5 分钟、训练约 22 分钟、放松 3 分钟；不赶组数，保留必要休息。
- 划船采用双臂俯身版；死虫式采用双臂固定的单腿伸展版；臀桥分别显示徒手与单哑铃说明。
- 教学步骤由助手依据来源改写，原库原文单独显示；未经专业人士逐条审核。核对清单见 coaching-review.md。
- 历史记录保留原动作、组数和重量，不自动迁移；新记录使用新版计划。

## 动态示范与许可

根目录电脑打卡版仍是纯文字版本，不自动请求远程媒体。`tv/` 包含目前电视版使用的本地 GIF、视频和来源记录，约 15 MB，部署后从同一站点加载。根目录电脑版教学面板仍会提示没有动态示范。

文字摘录来自 [exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset)，MIT 文字许可不等于独立媒体的再分发许可。来源链接供核对说明。

## 记录与同步

打卡仅保存于当前浏览器，不上传 GitHub，不跨设备自动同步。建议每周导出备份。更换访问地址、浏览器或设备前先导出，再在新页面导入；导入仅添加缺失日期，不覆盖同日记录。不要上传个人备份文件到仓库。

## 当前发布状态

此仓库现为公开仓库。根目录供电脑打卡，`tv/` 供 Vercel 电视站点部署。Vercel 关联由用户在现有项目控制台完成；仓库推送本身不会自动改变尚未关联的线上项目。不启用 GitHub Pages。
