# 晚间半小时

个人晚间抗阻训练手册。周一胸背、周二腿、周三核心、周四臀；每晚 21:00–21:30，周五至周日休息。

## 打开与使用

下载仓库后，在浏览器中打开根目录 `index.html`。无需安装依赖。

- 查看当天计划和动作分步说明、原创姿势示意、易错点与简化动作。
- 按实际情况调整组数，记录每只哑铃重量、次数和完成组数。
- 记录训练难度、胃部感受、疼痛与备注；第二天补记训练当晚的睡眠。
- 日期历史可查看与编辑。记录自动保存，也可以点击保存按钮确认。
- JSON 备份可导出、导入；导入只补充缺失日期，不覆盖已有同日记录。

## 记录保存

记录仅保存在当前浏览器，没有账户、服务端上传或跨设备自动同步。清理浏览器数据、使用无痕模式、换浏览器或更换访问地址可能找不到旧记录。

建议每周导出备份。从本地文件切换到线上网址时，先在本地导出，再到新网址导入。不要把个人记录备份上传到此仓库。

## 素材

本仓库版本使用动作中文教学和原创线条示意，不包含 Gym visual 图片或 GIF。本地完整媒体版仍保留在原项目中。

原库文字摘录参考 [exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset)，适用 MIT；原始说明见 `assets/NOTICE.txt`。原创示意只说明大致动作方向，不能评估实际姿势。
